> Bagaimana peran sistem operasi dalam mengelola perangkat keras komputer pada perusahaan tersebut?

Sistem operasi merupakan perangkat lunak yang mengatur segala proses mulai dari alat input komputer dan memproses data dari input user ke program aplikasi. Pada startup digital, sistem operasi membantu agar server, komputer karyawan, dan perangkat pendukung dapat digunakan secara teratur.

Sistem operasi mengatur penggunaan prosesor dengan menjadwalkan berbagai proses agar aplikasi, basis data, dan tugas lainnya dapat berjalan bersamaan. Sistem operasi juga membagikan kapasitas RAM sesuai kebutuhan setiap proses serta memisahkan ruang memorinya agar tidak saling mengganggu. Dalam pengelolaan penyimpanan, sistem operasi mengatur berkas, direktori, dan izin akses terhadap data.

Sistem operasi juga menghubungkan aplikasi dengan perangkat input/output melalui driver, seperti kartu jaringan, printer, dan pemindai. Dengan adanya driver, aplikasi dapat menggunakan perangkat tersebut sesuai fungsinya. Selain itu, sistem operasi membatasi akses pengguna terhadap sumber daya dan berkas berdasarkan kewenangan yang diberikan.

Sebagai contoh, startup yang memiliki sistem inventori seperti Livaza dapat menggunakan Linux sebagai sistem operasi server. Saat staf gudang mencatat transaksi dan manajer mengakses laporan pada waktu yang sama, sistem operasi mengatur penggunaan CPU, RAM, penyimpanan, dan jaringan agar layanan web dan MySQL dapat berjalan bersamaan.

Akan tetapi, penggunaan sistem operasi tertentu tidak langsung menjamin sistem akan stabil. Kinerja sistem juga dipengaruhi oleh kapasitas perangkat keras, pengaturan server, keamanan, serta pemeliharaan yang dilakukan secara rutin.

> Mengapa program aplikasi dan program utilitas sama-sama penting dalam mendukung kinerja sistem informasi?

Program aplikasi dan program utilitas sama-sama diperlukan karena memiliki fungsi yang saling mendukung. Program aplikasi digunakan untuk menjalankan pekerjaan perusahaan. Dalam kasus Livaza, aplikasi inventori membantu staf mengelola data barang, mencatat barang masuk dan keluar, serta membuat laporan persediaan. Dengan aplikasi tersebut, pengelolaan inventori dapat dilakukan tanpa sepenuhnya bergantung pada pencatatan manual.

Sementara itu, program utilitas digunakan untuk memelihara sistem dan melindungi data. Contohnya adalah utilitas pencadangan untuk menyimpan salinan basis data, pemantauan untuk memeriksa penggunaan CPU dan RAM, serta pemeriksaan storage untuk mendeteksi masalah penyimpanan. Utilitas keamanan juga dapat membantu mendeteksi ancaman terhadap sistem.

Dalam penerapannya, aplikasi inventori mencatat perubahan stok, sedangkan utilitas pencadangan membuat salinan basis data secara terjadwal. Jika data terhapus atau mengalami kerusakan, perusahaan dapat memulihkannya melalui cadangan yang telah diuji. Jadi, aplikasi membantu perusahaan menyelesaikan pekerjaan operasional, sedangkan utilitas menjaga agar sistem dan datanya tetap dapat digunakan.

> Bagaimana peran bahasa pemrograman dalam pengembangan dan keberlanjutan sistem informasi perusahaan?

Bahasa pemrograman digunakan untuk mengubah kebutuhan perusahaan menjadi instruksi yang dapat dijalankan komputer. Pada studi Livaza, aplikasi web dikembangkan menggunakan PHP, sedangkan data disimpan dan dikelola melalui MySQL. Dengan bahasa pemrograman, developer dapat membuat fitur pencatatan barang, pemeriksaan data, perhitungan stok, pengaturan hak akses, dan penyajian laporan.

Sebagai contoh, kode PHP dapat digunakan untuk memeriksa apakah jumlah barang yang akan dikeluarkan melebihi stok yang tersedia. Jika jumlahnya melebihi stok, aplikasi dapat menolak transaksi atau memberikan pemberitahuan kepada pengguna. Sementara itu, SQL digunakan untuk membaca dan memperbarui data yang tersimpan dalam MySQL.

Bahasa pemrograman juga memungkinkan sistem diperbaiki dan dikembangkan mengikuti perubahan kebutuhan perusahaan. Sebagai contoh, perusahaan dapat menambahkan pemberitahuan stok minimum atau menghubungkan aplikasi inventori dengan sistem penjualan. Sehingga untuk pemilihan bahasa pemrograman perlu disesuaikan dengan kemampuan tim, dukungan komunitas, ketersediaan library, dan dukungan keamanan. Agar sistem dapat terus digunakan dan dikembangkan, perusahaan juga perlu menyediakan dokumentasi, melakukan pengujian, mengelola versi kode, serta memperbarui dependensi yang digunakan.
