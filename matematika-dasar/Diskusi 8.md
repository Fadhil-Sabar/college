1. Diketahui A dan B dua himpunan berhingga
   |A| dan |B| merupakan bilangan kardinal, dari A dan B atau dalam bentuk lain yaitu n(A) dan n(B).
   
   Dua himpunan dikatakan dikatakan ekuivalen jika A ≈ B, jika terdapat sifat bijektif yaitu satu satu dan pada.
   
   **a. Bukti bahwa A ≈ B**
   
   Sebagai contoh:
   Misalkan |A| = |B| = n, sehingga anggota kedua himpunan dapat ditulis A = {a₁, a₂, …, aₙ} dan B = {b₁, b₂, …, bₙ}. Anggota di dalam masing-masing himpunan berbeda satu sama lain. Kemudian didefinisikan fungsi f : A → B dengan f(aₖ) = bₖ untuk k = 1, 2, …, n.
   
   Fungsi f bersifat satu-satu. Jika f(aᵢ) = f(aⱼ), maka bᵢ = bⱼ. Karena anggota B berbeda satu sama lain, maka i = j sehingga aᵢ = aⱼ. Artinya, anggota A yang berbeda selalu dipetakan ke anggota B yang berbeda.
   
   Fungsi f juga bersifat pada. Untuk setiap bₖ ∈ B terdapat aₖ ∈ A dengan f(aₖ) = bₖ, sehingga daerah hasil R(f) = B.
   
   Karena f bersifat satu-satu dan pada, maka f merupakan fungsi bijektif. Dengan demikian, A ≈ B (terbukti). Cara pembuktian ini sesuai dengan Contoh 8.1.2 pada BMP (Warsito, 2022, hlm. 8.5).
   
   **b. Apakah A=B**
   
   Dua buah himpunan dikatakan A = B jika anggota A sama dengan anggota B atau A ⊆ B dan B ⊆ A (Warsito, 2022, hlm. 8.4). Banyak anggota yang sama belum tentu anggotanya juga sama. Bisa dibuktikan juga pada Tes Formatif 1 di BMP, dimana pernyataan "jika A ≈ B maka A = B" bernilai salah, sedangkan "jika A = B maka A ≈ B" bernilai benar (Warsito, 2022, hlm. 8.11 dan 8.25).
   
   **c. Contoh himpunan yang ekuivalen tetapi tidak sama**
   
   Sebagai contoh, A = {1, 2, 3} dan B = {a, b, c}. 
   Kedua himpunan memiliki n(A) = n(B) = 3. Fungsi f dengan f(1) = a, f(2) = b, dan f(3) = c bersifat satu-satu dan pada, sehingga A ≈ B. 
   
   Namun, A ≠ B karena 1 ∈ A sedangkan 1 ∉ B. Contoh lain terdapat pada BMP, yaitu {1, 3, 5} dan {1, 7, 10} yang ekuivalen tetapi anggotanya berbeda (Warsito, 2022, hlm. 8.5).
   
   Perbedaan keduanya terletak pada hal yang dibandingkan. Kesamaan himpunan terlihat dari apakah anggota kedua himpunan sama, sedangkan himpunan ekuivalen hanya melihat apakah banyak anggotanya sama sehingga anggotanya dapat dipasangkan satu-satu. Dengan demikian, setiap himpunan yang sama pasti ekuivalen, sedangkan himpunan yang ekuivalen belum tentu sama.

2. Diketahui rumus 1 + 2 + 3 + … + n = n(n + 1)/2 untuk setiap n ∈ ℕ.

   **a. Bukti dengan induksi matematika**

   Misalkan S(n) adalah pernyataan 1 + 2 + 3 + … + n = n(n + 1)/2. Induksi matematika dilakukan dengan dua langkah. Langkah pertama memeriksa apakah S(1) berlaku, kemudian langkah kedua mengasumsikan S(k) berlaku dan menunjukkan bahwa S(k + 1) juga berlaku (Warsito, 2022, hlm. 9.15).

   **Langkah 1 (basis induksi)** 
   
   Untuk n = 1, ruas kiri bernilai 1 dan ruas kanan bernilai 1(1 + 1)/2 = 1. Kedua ruas sama, sehingga S(1) berlaku.

   **Langkah 2 (langkah induksi)** 
   
   Diasumsikan S(k) berlaku untuk suatu k ∈ ℕ, yaitu 
   1 + 2 + 3 + … + k = k(k + 1)/2
   
   Selanjutnya akan ditunjukkan bahwa S(k + 1) juga berlaku, yaitu 1 + 2 + 3 + … + k + (k + 1) = (k + 1)(k + 2)/2. Dengan menambahkan (k + 1) pada kedua ruas, diperoleh
   1 + 2 + 3 + … + k + (k + 1) = k(k + 1)/2 + (k + 1)
   = (k + 1)(k/2 + 1)
   = (k + 1)(k + 2)/2.
   Hasil ini sama dengan ruas kanan S(k + 1), sehingga S(k + 1) berlaku.

   Maka terbuktik, sebagai contoh untuk n = 4 diperoleh 1 + 2 + 3 + 4 = 10 dan 4(4 + 1)/2 = 10.

   **b. Apakah A = {1, 2, 3, …, n} berhingga atau tak berhingga**

   Himpunan A memiliki n anggota, sehingga n(A) = n. 
   
   Himpunan dengan n anggota, dengan n bilangan asli termasuk himpunan terhingga (Warsito, 2022, hlm. 8.12). A juga merupakan himpunan bagian sejati dari ℕ, sehingga sesuai Definisi 8.2.1a, A terhingga. Karena terhingga maka A juga termasuk himpunan terhitung (Warsito, 2022, hlm. 8.18).

   **c. Perbedaan himpunan sama, ekuivalen, berhingga, terbilang, dan tak terbilang**

   - Himpunan sama (A = B) berarti anggota A sama dengan anggota B, atau A ⊆ B dan B ⊆ A. Sebagai contoh {8, 6, 4, 2} = {6, 8, 2, 4}.
   - Himpunan ekuivalen (A ≈ B) berarti terdapat fungsi f : A → B yang bersifat satu-satu dan pada (Warsito, 2022, hlm. 8.4). Sebagai contoh {1, 3, 5} ≈ {1, 7, 10} dengan f(1) = 1, f(3) = 7, dan f(5) = 10 walaupun anggotanya berbeda (Warsito, 2022, hlm. 8.5).
   - Himpunan berhingga berarti himpunan tersebut ekuivalen dengan himpunan bagian sejati dari ℕ (Warsito, 2022, hlm. 8.12). Sebagai contoh {a, b, c, d, e, f} ≈ N₆ = {1, 2, 3, 4, 5, 6}, sehingga {a, b, c, d, e, f} berhingga (Warsito, 2022, hlm. 8.13).
   - Himpunan tak berhingga berarti himpunan tersebut ekuivalen dengan himpunan bagian sejatinya sendiri (Warsito, 2022, hlm. 8.13). Sebagai contoh G₂ = {2, 4, 6, …} ≈ G₄ = {4, 6, 8, …}, padahal G₄ merupakan himpunan bagian sejati dari G₂.
   - Himpunan terbilang berarti himpunan tersebut ekuivalen dengan ℕ (Warsito, 2022, hlm. 8.15). Sebagai contoh ℤ terbilang dengan f(1) = 0, f(2) = −1, f(3) = 1, f(4) = −2, dan seterusnya (Warsito, 2022, hlm. 8.16).
   - Himpunan tak terbilang berarti himpunan tersebut tak berhingga dan tidak ekuivalen dengan ℕ (Warsito, 2022, hlm. 8.16). Sebagai contoh himpunan bilangan irasional dan himpunan bilangan real ℝ.

   Sehingga dari penjelasan tersebut, kesamaan dan keekuivalenan membandingkan dua himpunan. Kesamaan melihat anggotanya, sedangkan keekuivalenan melihat banyak anggotanya. 
   
   Sedangkan berhingga, terbilang, dan tak terbilang menggolongkan satu himpunan berdasarkan banyak anggotanya. Himpunan berhingga dan himpunan terbilang termasuk himpunan terhitung, sedangkan himpunan tak terbilang seperti ℝ termasuk himpunan tak terhitung (Warsito, 2022, hlm. 8.18-8.19).
